# 🎬 mpv + ModernZ + Anime4K

Готовая, чистая и портативная сборка **mpv** с современным интерфейсом **ModernZ**, превью-кадрами на таймлайне (**thumbfast**) и оригинальными апскейл-шейдерами **Anime4K v4.0.1** (от `bloc97`).

Управление и горячие клавиши настроены в стиле классического **MPC-HC**.

---

## 🚀 Быстрая установка одной командой

Откройте **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/Hamich116/mpv-anime4k/main/install.ps1 | iex
```

Скрипт автоматически:
1. Скачает официальный свежий 64-битный движок `mpv`.
2. Развернёт все конфигурации, тему `ModernZ`, шрифты и шейдеры `Anime4K` в `C:\mpv`.
3. Создаст ярлык `mpv` на Рабочем столе.
4. Добавит пункт **«Play with mpv»** в контекстное меню файлов и папок.

## ⌨️ Управление (как в MPC-HC)

| Действие | Горячая клавиша / Мышь |
|---|---|
| **Пауза / Плей** | **ЛКМ** (клик по видео) или **Пробел** |
| **Полный экран** | **Двойной клик ЛКМ** или **F** / **Enter** |
| **Громкость** | **Колёсико мыши вверх / вниз** |
| **Перемотка 5 сек** | **Стрелки влево / вправо** |

## 🎚 Горячие клавиши Anime4K

Шейдеры переключаются на лету прямо во время просмотра:

| Сочетание | Пресет | Описание |
|---|---|---|
| **`Ctrl + 1`** | **Mode A (HQ)** | Оптимально для большинства 1080p |
| **`Ctrl + 2`** | **Mode B (HQ)** | Оптимально для 720p (мягкое сглаживание) |
| **`Ctrl + 3`** | **Mode C (HQ)** | Оптимально для 480p и старого аниме (сильный денойз) |
| **`Ctrl + 4`** | **Mode A+A (HQ)** | Двойной проход Mode A (максимальная чёткость контуров) |
| **`Ctrl + 5`** | **Mode B+B (HQ)** | Двойной проход Mode B |
| **`Ctrl + 6`** | **Mode C+A (HQ)** | Двойной проход Mode C + Mode A |
| **`Ctrl + 0`** | **Off** | Сбросить все шейдеры (оригинальная картинка) |

> 💡 Для слабых видеокарт доступны быстрые версии тех же режимов через **`Alt + 1`**, **`Alt + 2`**, **`Alt + 3`** и **`Alt + 0`**.

## 📂 Структура сборки

```text
C:\mpv\
├── mpv.exe                    # Движок mpv
└── portable_config\           # Конфигурация и расширения
    ├── mpv.conf               # Настройки видео, d3d11, sub-font
    ├── input.conf             # Бинды мыши и горячие клавиши Anime4K
    ├── fonts\
    │   └── modernz-icons.ttf  # Иконки кнопок интерфейса
    ├── scripts\
    │   ├── modernz.lua        # Интерфейс плеера
    │   └── thumbfast.lua      # Превью кадров над таймлайном
    └── shaders\
        └── Anime4K_*.glsl     # Шейдеры bloc97 Anime4K
```
